How it works

Each bit is worth a place value. A 1 means add that value. A 0 means ignore it.

1

Read the 8 bits from left to right.

2

Match each bit to its place value: 128, 64, 32, 16, 8, 4, 2, 1.

3

Add only the values under the bits that are switched on.
